👗 Capsule Wardrobe for AI Stylists
A curated dataset of versatile, transitional clothing pieces designed for everyday life. Girlies, this one's for you! <3

📋 Overview
This dataset was created specifically for training and testing AI Stylist models. It focuses on "capsule" pieces—items that are highly versatile and can be mixed and matched to create numerous outfits. This project was developed as part of the Kaggle AI Agents Intensive Capstone Project.

🏷️ Data Schema
Each item in this dataset is tagged with detailed attributes to help an AI agent understand style, context, and fit:

Category: The type of garment (e.g., Tops, Bottoms, Outerwear).

Color: The primary color palette.

Pattern: Textures and prints (e.g., Solid, Floral, Striped).

Season: Optimal weather for the piece (e.g., Transitional, Winter, Summer).

Occasion: Where to wear it (e.g., Casual, Work, Date Night).

Aesthetic: The style "vibe" (e.g., Minimalist, Coquette, Old Money, Streetwear).

Silhouette: The cut and shape (e.g., Oversized, Tailored, A-line).
